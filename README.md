# Causal Uplift Modeling for Incremental Advertising Targeting

A benchmark study of heterogeneous treatment-effect estimation and uplift ranking for incremental advertising targeting.

## Business Question

> "Which users are likely to convert **because** of the advertising intervention?"

This project focuses on **incremental impact (uplift)** — the causal effect of treatment on conversion — not just base conversion probability. A user who would have converted anyway provides zero incremental value from targeting.

## Causal Estimand

The **Conditional Average Treatment Effect (CATE)** is the core estimand:

$$\tau(x) = E[Y(1) - Y(0) \mid X = x]$$

where:
- $Y(1)$: potential outcome under treatment (ad exposure)
- $Y(0)$: potential outcome under control (no exposure)
- $X$: user features

Since we observe only one potential outcome per user (the **fundamental problem of causal inference**), we estimate $\tau(x)$ using meta-learner strategies.

## Core Estimators

| Estimator | Architecture | When It Works Best |
|-----------|-------------|-------------------|
| **Difference-in-Means** | $\hat{ATE} = \bar{Y}_{T=1} - \bar{Y}_{T=0}$ | Baseline; no heterogeneity |
| **S-Learner** | Single model on $(X, T) \to Y$; $\hat{\tau}(x) = \hat{\mu}(x,1) - \hat{\mu}(x,0)$ | When treatment effect is small relative to outcome variation |
| **T-Learner** | Two separate models $\hat{\mu}_1(x)$ and $\hat{\mu}_0(x)$; $\hat{\tau}(x) = \hat{\mu}_1 - \hat{\mu}_0$ | Balanced treatment arms |
| **X-Learner** | Pseudo-effects + propensity-weighted combination | Imbalanced arms; leverages abundant arm |

### X-Learner 5-Step Pipeline
1. Fit outcome models: $\hat{\mu}_1(x)$ on treated, $\hat{\mu}_0(x)$ on control
2. Compute pseudo-effects: $D^1_i = Y_i - \hat{\mu}_0(X_i)$ for treated; $D^0_j = \hat{\mu}_1(X_j) - Y_j$ for control
3. Fit effect models: $\hat{\tau}_1(x)$ on $(X_{\text{treated}}, D^1)$; $\hat{\tau}_0(x)$ on $(X_{\text{control}}, D^0)$
4. Get propensity: $\hat{e}(x)$ (constant for Criteo, estimated for IHDP, true for synthetic)
5. Combine: $\hat{\tau}(x) = (1 - \hat{e}(x)) \cdot \hat{\tau}_1(x) + \hat{e}(x) \cdot \hat{\tau}_0(x)$

## Evaluation & Conventions

### Qini Convention
The Qini calculation follows this specific convention:
1. Rank units by predicted uplift $\hat{\tau}$ in descending order.
2. At each fraction $f$ of the population:

$$Qini(f) = \frac{\sum Y_{T=1, \text{top}_f}}{N_{\text{treated\_total}}} - \frac{\sum Y_{T=0, \text{top}_f}}{N_{\text{control\_total}}} \times \frac{N_{\text{treated\_in\_top}_f}}{N_{\text{treated\_total}}}$$

3. The **Qini coefficient** = Area under the Qini curve minus the random baseline area.

### Naming Convention
- `mean_predicted_effect(tau_hat)`: the average of estimated conditional treatment effects. This is a **model output average**, not automatically a causally-identified ATE unless identification assumptions hold.
- `compute_ate_error()`: requires ground truth (IHDP/synthetic only).
- `compute_pehe()`: raises `ValueError` if called on Criteo (no counterfactuals available).

### Identification Assumptions
- **Unconfoundedness** (no unmeasured confounders): Assumed for IHDP estimators. Criteo guarantees via randomization. Stress-tested in E5.
- **Overlap** (positivity): $0 < P(T=1|X) < 1$. Stress-tested in E3.
- **SUTVA** (no interference): Assumed — one user's treatment does not affect another's outcome.

## Known Failure Modes

1. **Feature leakage**: Including `exposure` or `visit` as features would leak post-treatment information.
2. **Treatment definition error**: Confusing `exposure` with `treatment` in Criteo.
3. **Outcome timing**: Using outcomes measured before treatment assignment.
4. **Weak overlap**: Extrapolating treatment effects where propensity → 0 or 1.
5. **Metric misuse**: Computing PEHE on Criteo (no individual counterfactuals available); using accuracy on 0.29% conversion data.
6. **Propensity overfitting**: Fitting a flexible propensity model on Criteo's randomized data learns noise.
7. **Confounding claims**: Meta-learners do NOT solve hidden confounding — they require unconfoundedness.

## Limitations

- This is an **offline benchmark study**, not a production causal system.
- Production deployment would require a **controlled online randomized experiment** to validate the targeting policy.
- The project does NOT claim to have invented a novel causal algorithm.
- IHDP results are based on semi-synthetic data; real-world causal effects may differ.
- The X-Learner is not universally superior to T-Learner; performance is data-dependent.

## Setup & Reproduction

```bash
# 1. Activate the isolated local environment (no global system packages affected)
source .venv/bin/activate

# 2. Install dependencies
pip install --no-cache-dir -e .

# 3. Run individual experiments
python -m src.experiments.e0_baseline --config configs/dev.yaml
python -m src.experiments.e1_estimator_comparison --config configs/dev.yaml
python -m src.experiments.e2_imbalance --config configs/dev.yaml
python -m src.experiments.e3_overlap --config configs/dev.yaml
python -m src.experiments.e4_predictive_vs_causal --config configs/dev.yaml

# 4. Run tests
PYTHONPATH=$(pwd) pytest tests/ -v

# 5. Full reproduction (requires Criteo data + more time)
python -m src.experiments.run_all --config configs/full.yaml
```

**Disk management**: All packages are in `.venv/` (like `node_modules`). Delete `.venv/` to reclaim 100% of the space. Zero global system impact.

- `dev.yaml`: 1% Criteo sample (~140K rows), 1 IHDP replication, 3 seeds — fast iteration.
- `full.yaml`: Full Criteo, 10 IHDP replications, 5 seeds — final benchmark.
